## 0. 一句话结论

```text
ColorOS 有一套【专门给三方耳机】的降噪接口，
通过 IOplusRemoteDevice 暴露 —— 就是我们已经用来推电量的那个接口。

三方耳机只要：
    ① 声明能力位（支持降噪/通透/...）
    ② 实现 setNoiseMode / getNoiseMode
系统就会把它当官方耳机对待：显示降噪开关、下发指令、回显状态。

→ 不需要 hook 任何 UI。
→ 我们此前找错方向了（在 com.android.bluetooth 里找 UI 钩子）。
```

## 9. 用户已确认的产品决策

```text
ColorOS 只有 3 个状态（关 / 开 / 通透），
T6 有 5 档（关 / 深度 / 中度 / 轻度 / 环境音）。

用户选择：
    "开启" = 深度降噪
    其余档位（中度/轻度）留给"后加长按手势"或官方 APP

→ 实现时：changeAncMode 收到"开"就发 A1（深度）
```

# 11. ★ 第二轮挖到的完整实现细节（jadx 反编译 oplus jar）

## 11.1 系统对三方耳机有两套机制

```text
机制 A：AirPods 式（自定义管理器）   ← ★ 我们走这条
    位于 com.oplus.bluetooth.feature.airpods.AirPodsManager
    系统【把控制权交给管理器】，具体发什么命令由管理器决定

机制 B：AT 协议式（+OBUDS）
    位于 com.oplus.bluetooth.feature.atext.OplusThirdPartyEarbudAtHandler
    耳机需走 HFP AT 通道，用 AT+OBUDS=... 收发
    T6 不支持这个协议 → 走不通
```

```text
[为什么选机制 A]
    系统只调用管理器的 setNoiseMode(device, mode) / getNoiseMode(device)，
    【具体发什么命令完全由我们决定】——
    我们就发 T6 的 AA BB CC 09 01 xx。
    ColorOS 内部逻辑我们一点不用管，耦合度最低。
```

```java
// setNoiseMode 的实际实现（AirPods 的私有协议，我们换成 T6 的）
public boolean setNoiseMode(BluetoothDevice device, int mode) {
    if (mode < 1 || mode > 4) return false;         // 系统只给 1..4
    OutputStream out = getDeviceOutputStream(device);
    if (out != null) {
        byte[] cmd = {4,0,4,0,9,0,13,(byte)mode,0,0,0};
        out.write(cmd);
    }
    return true;
}
```

## 11.7 下一步实现（机制 A）

```text
目标：让系统为 T6 显示降噪开关，并把开关动作转成 T6 命令

第 1 步：取 IOplusRemoteDevice 实例
         OplusFeatureCache.get(IOplusRemoteDevice.DEFAULT)
         （ColorOsBatteryBridge 已有此代码，直接复用）

第 2 步：为 T6 声明降噪能力
         setOplusDeviceNoiseModeSupport(device,
             mask = FEATURE_EXT_NOISE_MODE | FEATURE_EXT_NOISE_TRANSPARENT,
             noiseMode = 当前模式)
         注意：mask 的位含义见 11.3（位1/位2=降噪，位4=通透）

第 3 步：Hook 系统读取降噪状态的方法，返回我们的值
         （让系统 UI 显示正确的当前档位）

第 4 步：Hook 系统下发降噪指令的方法
         收到 mode → 翻译成 T6 命令 → 通过已有 BLE 通道发出
             关   → AA BB CC 09 01 A0 A0 2A
             深度 → AA BB CC 09 01 A1 61 EA   （用户选择：开启=深度）
             通透 → AA BB CC 09 01 C2 21 C3
         然后 notifyNoiseModeChanged(device, mode) 回显状态

第 5 步：真机验证系统蓝牙页是否出现降噪开关
```
